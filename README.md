# Smileawhile Dental: website redesign

Static, WordPress-portable build: Vite + semantic HTML partials + modern CSS (custom properties, no framework) + vanilla ES modules, with GSAP (ScrollTrigger, SplitText) and Lenis.

## Status
- **Phase 1 (Step 0):** design system + wireframe, approved.
- **Phase 2:** header + hero built, **awaiting approval**. Below the hero is a temporary dev stub (`.dev-stub`) that exists to test header scroll states and the `#appointment` anchor.

## Commands
```bash
npm install
```
```bash
npm run dev
```
```bash
npm run build
```
```bash
npm run preview
```
Regenerate responsive images after changing crops or the grade:
```bash
npm run images
```
Rebuild the Step 0 styleguide (`preview/system.html`, self-contained, open directly):
```bash
python3 scripts/build-preview.py
```

## Structure
```
index.html                         page shell: head, schema, includes partials
src/data/site.json                 clinic facts: name, phone, address, PLACEHOLDER hours, nav, services, hero copy
src/data/images.json               generated by `npm run images` (intrinsic sizes for width/height)
src/sections/<name>/               one folder per section: <name>.html + .css + .js  → WP template part
  header/                          sticky header, mega-menu, mobile menu
  hero/                            hero
src/styles/tokens.css              design tokens (→ theme.json)
src/styles/base.css                reset, type utilities, layout, a11y, placeholder flag
src/styles/components.css          buttons, links, glass tile, wordmark
src/styles/dev-stub.css            TEMPORARY, delete in Phase 3
src/js/main.js                     entry; imports styles + boots sections
src/js/motion.js                   GSAP/Lenis setup, house easing, durations, reduced motion
src/js/magnetic.js                 magnetic CTA
src/icons/glass-icons.svg          glass icon sprite (inlined into the page)
build/html-partials.js             tiny Vite plugin: @include, {{site.*}}, {{#each}}, {{#if}}, @picture
public/fonts/                      Google Sans Variable, Latin WOFF2 subset (77 KB; the 5 MB TTF is not committed)
public/images/holland/             processed photos (AVIF + WebP, 480–1600w)
assets/images/holland/_source/     original photos from holland-smiles.com (never served)
assets/images/                     client clinical photos (processed in Phase 3)
scripts/process-images.mjs         crop → grade → AVIF/WebP pipeline
scripts/palette.py                 OKLCH ramp generator + contrast check
docs/                              sitemap, content gaps, photo inventory
preview/                           Step 0 styleguide (source + built)
```

## Content rules
- Clinic facts live only in `src/data/site.json`. Hours there are **PLACEHOLDERS** and are deliberately not in the Dentist schema.
- Unconfirmed visible content carries `data-placeholder` and shows a dashed amber flag while `showPlaceholders` is `true`. Set it to `false` at launch.
- No "24/7", "day or night", "on-call" or out-of-hours emergency claims anywhere (the practice does not take emergency calls).

## WordPress mapping (summary)
| Here | WordPress |
|---|---|
| `src/sections/*/*.html` | `template-parts/*.php` |
| `{{site.*}}` | Theme options / ACF options page |
| `{{#each site.services}}` | Services CPT or nav menu loop |
| `<!-- @picture … -->` | `wp_get_attachment_image()` (srcset + sizes) |
| `tokens.css` | `theme.json` palette / typography / spacing |
